# Сравнение моделей на длинных файлах и смешанной речи

[Замер по публичным эталонам](human-reference-wer.md) сравнивает 21 конфигурацию
на FLEURS, CS-FLEURS Read и 41 минуте вычитанного подкаста Podlodka.

## Сводная таблица в Камертоне

Таблица объединяет семь наборов и 21 конфигурацию. По умолчанию видны пять
метрик качества по публичным эталонам FLEURS, CS-FLEURS Read и Podlodka.
Кнопка "Все показатели" раскрывает скорость, серверные и архивные замеры
в той же таблице. Заголовок метрики переключает порядок сортировки.

Места рассчитаны отдельно для каждой метрики на конкретном наборе. Для WER,
RTF и количества ошибок первое место у меньшего значения. Для доли правильных
ответов оно у большего. При равенстве модели делят место, следующее место
учитывает число моделей, которые стоят выше. Прочерки исключены из расчета.
Обозначения первых трех мест следуют практике [Open ASR Leaderboard](https://huggingface.co/spaces/hf-audio/open_asr_leaderboard/blob/main/app.py).

Под названием модели указано ее наивысшее место по основным метрикам или
серверному RTF. При равенстве остается первая метрика по порядку столбцов.
Серверный WER показывает расхождение с расшифровкой Soniox на восьми
записях без человеческой разметки. Этот замер находится в полном отчете под
заголовком "Сервер · сверка с Soniox".

## Серверный замер

AMD Ryzen 5 5600G, Linux, Docker, без GPU. В первом прогоне на контейнер
выделили до трех CPU и 3 ГиБ памяти, один запрос за раз. GigaSTT, Whisper и T-one настроены на три
потока. Parakeet.cpp использовал штатную настройку потоков внутри ограничения.
Один проход после прогрева, фиксированный язык ru. Для GigaSTT, Parakeet,
Nemotron и T-one вызов сделан штатным бенчмарком через Камертон. Whisper
измерялся через локальный whisper-server 1.9.6, beam 5, без контекста
предыдущего окна. При одновременных замерах работали отдельные контейнеры
с отдельными лимитами CPU и памяти. Результаты включают влияние нагрузки
общей машины.

Первый прогон покрывал 13 моделей. 27.11.2026 на том же сервере и тех же
файлах последовательно проверили v4 RNN-T, v4 CTC и Multilingual v2 RNN-T
через штатный бенчмарк Камертона. Для них использовали CPU-версию PyTorch,
три потока, лимит 4,5 ГиБ, отдельный прогревочный файл и язык `ru`. Все 16
моделей ответили на 128 запросов по восьми записям, в том числе на отрывок
9 мин 45 с целиком. Еще 48 запросов проведены на контрольных фразах.

## Воспроизведение

[Штатный бенчмарк](../../bench/README.md) загружает файл через `/api/test`.
Для сравнения скорости нужны одинаковые файлы, число CPU и параметры
декодирования. RTF равен времени обработки, деленному на длительность аудио.
Длительность можно брать из `ffprobe`, в частности для MP3 в GigaSTT.

В [наборе контрольных фраз](../../bench/ru-mixed-reference.json) есть редкие
русские слова, технический сленг, русское произношение английских терминов
и числа в нескольких формах. Совпадение с латинским написанием оценивается
отдельно от числового значения. Для WER на реальных разговорах нужен
независимый эталон. Это особенно важно при сравнении моделей той же семьи,
к которой относится модель машинной расшифровки.
