# GigaAM v4 CTC, v4 RNN-T и Multilingual v2 на CPU

Проверка от 27.11.2026 через `POST /api/test` и клиент из `bench/bench.py`. Все модели получили одинаковые файлы на одном локальном CPU. Для v4 использовались 3 потока PyTorch, для GigaSTT 2.22.0 - размер пула и число параллельных окон 1. Это один прогретый запрос на файл и модель. Время загрузки весов и запуска движка в таблицу не входит.

| Синтетическая запись | Длина | v3 июнь, с | v3 октябрь, с | v4, с | Multilingual v2, с |
| --- | ---: | ---: | ---: | ---: | ---: |
| Русская фраза | 13,4 с | 0,92 | 0,43 | 0,98 | 2,31 |
| Русский с английским | 15,8 с | 1,32 | 0,75 | 0,90 | 2,19 |
| Повтор русской фразы с паузами | 1:12 | 5,69 | 2,61 | 4,44 | 11,22 |
| Повтор русской фразы с паузами | 9:22 | 41,13 | 14,09 | 43,88 | 85,75 |

| Эталон | Слов | WER v3 июнь | WER v3 октябрь | WER v4 | WER Multilingual v2 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Русский | 14 | 7,14% | 7,14% | 0,00% | 0,00% |
| Русский + английский | 23 | 47,83% | 47,83% | 8,70% | 34,78% |

WER рассчитан с нормализацией из `bench/bench.py`. В русской фразе все модели записали цифрами оба числа. В смешанной фразе синтезаторы по отдельности произносили русский текст и английские названия. Длинные образцы проверяют обработку окон и задержку. Для оценки качества на разговорной речи нужна размеченная выборка. Результаты локального CPU не переносятся на рабочий сервер без замера.

Multilingual v2 проверена отдельным прогоном на тех же файлах и компьютере, с тремя потоками PyTorch и автоопределением языка. GigaAM v4 CTC проверили на тех же синтетических файлах в Docker с тремя потоками CPU: 0% WER на русском, 17,39% на смешанной фразе, оба числа сохранены. Запись на 9:22 заняла 27,10 с. Данные доступны в разделе "Бенчмарк WER" веб-консоли.

Для проверки казахского языка взяли первые шесть файлов тестового архива `kk_kz` с эталонами. В обоих режимах, `language=auto` и `language=kk`, получено 6 ошибок на 116 слов (WER 5,17%). Это проверка поддержки языка на небольшой выборке. [Ревизия FLEURS](https://huggingface.co/datasets/google/fleurs/tree/70bb2e84b976b7e960aa89f1c648e09c59f894dd/data/kk_kz)

## Проверка контейнера

В образе `gigaam-v4` развертывание из уже скачанных весов прошло с отключенной сетью. Два одновременных запроса к v4 и октябрьской v3 завершились HTTP 200. Каждый запрос прошел через распознавание и вернул оба числа из тестовой фразы.

Multilingual v2 в контейнере с 3 CPU и лимитом 6 ГиБ дошла до готовности за 34,9 с. `memory.peak` составил 4797 МиБ после запуска и 5120 МиБ после обработки записи 1:12. В пиковое значение входит память всей среды контейнера и файловый кеш. Два одновременных запроса к Multilingual v2 и GigaAM v4 также получили HTTP 200.

Для v4 CTC проверены чистая загрузка с Hugging Face, контрольные суммы, развертывание, появление `gigaam-v4-ctc` в API и длинная запись. Первый запрос `verbose_json` через API вернул текст с отметками времени, повтор вернул тот же ответ из кеша. [Ревизия весов v4 CTC](https://huggingface.co/ai-sage/GigaAM-v4/tree/5b81216afa29c8b5a1a3e64c424c8416e18c1e5b)

Все три модели также проверены на [серверной выборке](asr-benchmarks.md#серверный-замер) вместе с первым поколением Multilingual CTC и CTC Large.
